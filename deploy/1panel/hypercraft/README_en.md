## Introduction

**Hypercraft** is a cross-platform process management and monitoring system for Minecraft servers and other long-running processes.

## Features

- **Process Management**: Start, stop, restart and kill processes, with auto-restart and graceful shutdown commands.
- **Web Terminal**: Interactive WebSocket + PTY terminal attached to the running process.
- **Logs**: History tail, live follow and automatic truncation.
- **Scheduling**: Cron-based scheduled start, stop and restart.
- **Permissions**: Super admin, system admin and user roles with per-service ACL.
- **Agent API**: Long-lived API keys and /agent/* endpoints for automation.
